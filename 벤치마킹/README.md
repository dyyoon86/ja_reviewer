## 공통 성공 패턴 (4채널 모두)

1. **결말 스포 금지 + 질문형 마무리** — 궁금증을 남긴 채 끊는다.
2. **검열 회피 은어를 '유머'로 승화** — 운동, 비타민, 간병, 바지 지표… 순화가 곧 개그.
3. **고정 시그니처 멘트** — 오프닝/클로징 문장이 채널 브랜드.
4. **솔직 평가(호불호 명시)** — 칭찬만 하는 리뷰는 없다. "아쉽다"가 신뢰를 만든다.
5. **시청자 질문 대리 해소** — "왜?"를 먼저 던지고 먼저 답한다 (락규 팩트체크, 3분휴지 떡밥 질문).

## 우리 내레이션이 재미없는 이유 (진단)

ja12 현재 내레이션: *"첫 번째 작품은 나나시마 마이입니다. 레이블은 ABF, 청초한 마스크입니다. 이번 컨셉은 영화관 아르바이트생입니다."*

- ❌ 전부 **평서문 설명** — 질문/떡밥/리액션이 0개
- ❌ 관찰자 시점만 있고 **리뷰어 페르소나(1인칭 감상)** 가 없음
- ❌ 추상 형용사("청초한") — 장면이 안 그려짐
- ❌ 심리 해설·전환점 멘트 없음 — 컷과 컷이 나열로만 이어짐
- ❌ 시그니처 멘트/평가 지표 같은 반복 브랜딩 장치 없음
