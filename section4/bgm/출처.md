## 교체

`tools/section4_intro.py` / `tools/section4_outro.py` 의 `BGM_SRC` / `BGM_OFFSET` 두 줄만 바꾸면 된다.
빌드가 길이에 맞춰 자르고 페이드·라우드니스를 맞춘다.
이미 빌드된 배치는 build 를 다시 돌리지 말고(회차 문구가 오늘 기준으로 바뀜) `{out}/_인트로/hf/assets/bgm.mp3` 만 같은 필터로 갈아끼운 뒤 render.

## 원곡 mp3 는 저장소에 없다

`.gitignore` 로 뺐다. 새로 받으려면:

```bash
cd section4/bgm
curl -sL -o secret_garden.mp3 https://assets.mixkit.co/music/595/595.mp3
curl -sL -o house02.mp3       https://assets.mixkit.co/music/744/744.mp3
curl -sL -o gummies.mp3       https://assets.mixkit.co/music/1142/1142.mp3
```
