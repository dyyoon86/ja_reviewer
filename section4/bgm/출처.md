# 인트로 BGM

모두 **Kevin MacLeod (incompetech.com)** / **CC BY 4.0**.
받은 곳: `https://incompetech.com/music/royalty-free/mp3-royaltyfree/<제목>.mp3`

| 파일 | 곡명 | 성격 | 쓸 구간 | 상태 |
|---|---|---|---|---|
| `sneaky_snitch.mp3` | Sneaky Snitch | **가볍고 경쾌·장난기(피치카토)** | 40s~ | **현재 사용** |
| `life_of_riley.mp3` | Life of Riley | 밝고 산뜻한 팝 | 20s~ | 대안 |
| `pixel_peeker_polka.mp3` | Pixel Peeker Polka (faster) | 빠르고 코믹한 폴카 | 40s~ | 대안 |
| `carefree.mp3` | Carefree | 아주 가벼운 어쿠스틱 | 60s~ | 대안 |
| `clash_defiant.mp3` | Clash Defiant | 웅장·긴박(타악) | 112s~ | 보류 — "너무 무겁다"(2026-09-08) |

구간은 곡 전체를 14초 단위로 훑어 평균 음량이 가장 높은 지점을 실측해 골랐다.

## 교체

`tools/section4_intro.py` 의 `BGM_SRC` / `BGM_OFFSET` 두 줄만 바꾸면 된다.
빌드가 인트로 길이에 맞춰 자르고 페이드·라우드니스를 맞춘다.

## 원곡 mp3 는 저장소에 없다 (38MB)

`.gitignore` 로 뺐다. 새로 받으려면:

```bash
cd section4/bgm
for n in "Sneaky%20Snitch" "Life%20of%20Riley" "Carefree" \
         "Pixel%20Peeker%20Polka%20-%20faster" "Clash%20Defiant"; do
  curl -sL -o "$n.mp3" "https://incompetech.com/music/royalty-free/mp3-royaltyfree/$n.mp3"
done
```
받은 뒤 파일명을 위 표대로 바꾼다(`sneaky_snitch.mp3` 등).
