# 딸딸기튜브 신작 해설 내레이션 (품번+SRT → 2트랙 SRT)

상세 배경: `jav_scrap/docs/ddalddalgi-narration.md`. 번역은 [[jav-subtitle-translate]] 스킬 사용.

## 입력
- **일본어 SRT** (작품 대사, 타임코드 포함) — 사용자가 줌
- **품번** (예: SNOS-183) — DB 조회 키

## 워크플로우

### 1) 품번으로 DB 정보 싹 긁기
`jav_scrap/gen_narration.py` 의 `fetch_meta(con, code)` 사용(또는 동일 SQL):
- works: 배우(한/일)·레이블·메이커·감독·시리즈(series_ja)·일본원제(title_ja)·**한국어 시놉시스(description)**·발매·런타임·태그·인기(views/likes/dislikes)
- actresses 조인: **스리사이즈 실수치**(bust/cup/waist/hip/height)·생일·혈액형
```bash
cd /home/dyyoon/jav_scrap && ./venv/bin/python -c "
import sqlite3,gen_narration as g
m=g.fetch_meta(sqlite3.connect('jav_2026.db'),'<품번>'); print(m); print(g.meas_str(m))"
```

### 2) 풀 SRT에서 스토리 대사만 추출 → 번역
- **풀 SRT 전체를 스캔**하되, 아래는 **제외**:
  - 신음·짧은 탄성·반복 감탄(あぁ/イク 류), 의미 없는 짧은 라인
  - 단순 섹스 장면의 비스토리 대사
- **남기는 것 = 스토리 전개에 필요한 대사**: 설정·관계·상황 전환·갈등·결말을 드러내는 대사 (도입부만이 아니라 **전체 타임라인에 걸쳐** 듬성듬성 추출).
- 추출한 스토리 대사만 [[jav-subtitle-translate]] 규칙으로 번역. Whisper 오인식은 맥락으로 복원.
- → `<원본>.대사.srt` (원본 타임코드 유지, 한국어 대사. 섹스 구간은 비어 있음).
- ※ 토큰 절약은 "초반부 자르기"가 아니라 **"선정적·반복 제거"**로 달성한다.

### 3) 내레이션 생성 (리뷰형 + 장면 해설)
DB 메타 + SRT 줄거리를 합쳐, **3분휴지 스타일**로 작성:
- **톤**: 정중체(~습니다) + 솔직 호불호 + 마니아 은어(미드/포텐/피지컬/육덕/하메리/1인칭/펠라/시추에이션 등) + 레이블(S1·마돈나…) 맥락.
- **구성**: 전환("다음은 ○○○의 신작입니다") → 시놉시스 → 솔직 평가(피지컬·컨셉적합·완성도) → 총평. + 장면 해설("보시는 것처럼 ○○하는 상황…").
- **사실성**: 배우·신체·레이블·시놉시스·인기는 DB 근거. 영상 디테일(연기·완성도·비교)은 **창작(옵션2)**, 설정과 모순 없게.
- **별점**: 인기지표(좋아요/싫어요 비율) 참고해 ★1~5.
- 각 내레이션 문장을 **영상 타임라인 지점**에 배치(인트로 공백 + 전환점 + 코멘트 포인트). 원음 무음 구간(긴 한마디·몽타주)에 얹어도 됨.
- → `<원본>.내레이션.srt`.

### 4) 출력 = B안 2트랙
- `<원본>.대사.srt` + `<원본>.내레이션.srt` **별도 2파일**.
- 편집기에서 각각 다른 자막 트랙으로 → 위치/색 따로, 동시 표시. 내레이션 구간 원음 무음.
- 만든 뒤 `cokacdir --sendfile` 로 두 파일 전송.

## 규칙/한계
- **풀 SRT 전체를 본다**(초반부만 자르지 말 것). 단 **스토리에 필요한 대사만 추출**해 처리 → 토큰 절약은 "선정적·반복 제거"로 달성.
- **선정적 대사 제외**: 신음·단순탄성·반복 감탄·비스토리 섹스 대사는 빼고, 설정·관계·전개·결말 대사만 남긴다.
- **전체 전개 커버**: 도입~중반~결말까지 스토리 흐름을 다룬다. 섹스 장면 구간은 대사 대신 내레이션으로 브릿지("이후 호텔로 자리를 옮겨…").
- **codex 토큰 revoke 상태**라 gen_narration.py 무인실행 불가 → 현재는 이 스킬로 **Claude가 직접** 번역·작성. (API 키 붙으면 자동화)
