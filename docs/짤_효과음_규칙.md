# 짤·효과음 규칙 (2026-10-07 확정)

사용자 피드백: ja10 때 넣어 봤더니 **짤이 너무 길고 효과음이 별로**였다. 시안 v2(START-640)로 확정한 값.

## 어디서 결정되나
- **대본 단계**(`rank_renarrate --style story` → `regen_narration`): LLM이 줄마다 `sfx` 역할과 `cutin` 태그를 함께 낸다.
  `{code}_내레이션.json` 에 그대로 저장된다.
- **해설자막 단계**(`add_narsub.py`): json 태그 + srt 실측 시각으로 짤 오버레이와 효과음을 한 번에 입힌다.
  태그가 없는 옛 대본이면 아무것도 안 한다. `--no-cutins` / `--no-sfx` 로 끌 수 있다.

## 효과음 — 해설 줄마다 하나
| sfx 역할 | 언제 | 파일(assets/sfx/) |
|---|---|---|
| 호명 | 첫 줄 "N위, 배우." | call_rank(두둥탁) |
| 정보 | 상황 설명 | info(띠링) · info2(또링) 교대 |
| 반전 | 사건이 뒤집히거나 들키는 줄 | twist(뜨업) · shock(또익 놀람) 교대 |
| 긴장 | 질투·불안·망설임 | sweat(땀 삐질) · sweat2(땀) 교대 |
| 드립 | 가볍게 웃기거나 받아치는 줄 | pop(뾱) · pop2(팝) · pop3(짧은 팝) · boing(뚀익) 순환 |
| 마무리 | 마지막 줄 | finale(따단딴딴) |

- 발화 시작 0.05초 전에 깐다. 음량은 원본 피크 ±1dB(해설 아래). 두둥탁만 -9dB 추가(처음에 7dB 튀었다).
- 소스는 사용자 효과음 모음(`E:\01.youtube\자생법\…\01_저작권표시필요없음`, 저작권 표시 불필요). `loudnorm I=-17~-21:TP=-4` 로 맞춰 48k wav.
- 배치 폴더 `{out}/_sfx/{이름}.wav` 가 있으면 그것이 우선(회차별 교체용).

## 짤 — 편당 최대 2개(1~3위 3개)
- `cutin` 태그는 첫 줄·마지막 줄에 안 붙고, 반전·어이없는 말·민망한 순간에만.
- 태그 10개 = `assets/gifs/{태그}/` 폴더명: 놀람·어이없음·실망·흥분·웃음·의심·긴장·민망·뿌듯·허무. 폴더가 비면 그 태그는 조용히 건너뛴다.
- 발화 0.2초 뒤 등장, **2.5초** 유지. 좌하단(x=60, 바닥 770px = 해설 자막판 위), 폭 22%. 0.15초 페이드 + 0.25초 슬라이드업.
- 첫 5.6초(인포카드)·마지막 3초엔 안 띄운다. 같은 태그가 반복되면 폴더 안 파일을 돌려 쓴다.
- 소재 규칙: Giphy에서 **사람이 골라 로컬 저장**(렌더 중 API 호출 금지). 유명인 얼굴·워터마크 박힌 것·텍스트 밈·노출 짤 제외. 디카프리오 박수 짤은 이 규칙으로 뺐다(뿌듯 폴더 비어 있음).
