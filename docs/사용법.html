3. 풀오토 자세히

동작 방식

  • 5초마다 감시 폴더를 확인. 파일 크기가 두 번 연속 같으면(=다운로드 완료) 큐에 투입
  • 대상 확장자: mp4 · mkv · avi · ts · wmv · mov
  • 한 번 처리한 파일은 기억(watch_seen.json) — 서버 재시작해도 중복 투입 없음
  • 품번을 파일명에서 못 읽으면 큐에 "품번 입력 필요"로 대기 → 클릭해서 품번만 넣으면 진행
  • voicebox·meta_api가 죽어 있으면 에러 대신 60초 간격 자동 재시도 — 던져놓고 자리 비워도 됨

풀오토 프리셋 (자동 적용)

항목값
길이1분 (config target_sec)
오프닝단독(solo) — "이번 작품은 ○○의 신작입니다" + 마무리 인사로 완결
문체3분휴지형 (담백한 총평)
TTS윤두영일반 보이스 · 원음 덕킹(해설 중 원음 30%) · 먹싱 포함
번인자막 + 인포배너 + 워터마크까지 구움
⚠ 노출 안전장치 — 트림 없이 원본을 던지므로, AI가 고른 구간 중 대사가 한 줄도 없는 keep(정사장면 의심)은 자동 제외됩니다(로그에 ⚠ keep … 대사 0줄). 그래도 업로드 전 완성본은 꼭 눈으로 검수하세요 — 대사가 있는 노출 장면까지 걸러주진 못합니다. 확실히 하려면 ① 잘라내기로 정사장면을 먼저 빼고 큐에 넣는 게 안전합니다.

4. 수동 워크플로우 — 단계별로 직접

① 잘라내기 (선택 구간 삭제)

  • 영상 열기 → 내장 플레이어에서 정사장면 구간 마킹 (또는 텍스트로 12:30-18:00, 45:00-52:00)
  • 단축키: Space 재생/정지 · [/I 구간시작 · ]/O 구간끝 · ←→ 5초
  • 기본 컷은 스마트 컷(경계만 재인코딩+중간 카피 — 2시간짜리도 수십 초, 프레임 정밀). 실패 시 자동 폴백
  • "정밀(재인코딩)" 체크는 전체 재인코딩 강제 — 보통 필요 없음

② 단계 실행 (전사 → AI → 자막)

  • 품번 입력 후 각 단계 실행 버튼. 중간에 실패하면 그 단계만 다시(앞 단계 결과 재사용)
  • 방식: 짜집기(요약형)=줄거리 고루 / 알파컷(하이라이트형)=후킹 순간 몰아서
  • 문체: 3분휴지형(원음 끄고 총평) / 고몽·김시선형(대사와 주고받기, 원음 살림)
  • 위치: 단독(하나로 완결) / 먼저·다음은·마지막으로(묶음 리뷰 꼭지) / 자동(큐 순서)
  • AI가 거부/빈 응답이면 🛠 수동 모드: 프롬프트 복사 → claude/codex에 직접 붙여넣기 → 결과 JSON 붙여넣기

③ TTS · 자막굽기 · 인포배너

  • TTS: 보이스 선택 → 내레이션 SRT를 문장별 합성 → 원음 덕킹 먹싱
  • 굽기: 대사(하단 흰/남자 하늘색)·내레이션(상단 노랑)·강조·정보 스타일 템플릿 3종
  • 배너: 품번으로 메타 조회 → 인포카드+워터마크 투명 PNG → 굽기와 같은 1패스에 합성

5. 작업 큐 — 여러 편 묶음 처리

  • ＋ 영상 여러 개 추가 → 자동 진행할 단계 체크(전사~번인) → 알아서 순차+병렬 처리
  • 리소스 레인: GPU 1 · AI 2 · TTS 1 — A가 전사하는 동안 B는 LLM 처리 (VRAM 충돌 없음)
  • 큐 순서 = 묶음 영상의 편집 순서 — 전환 문구(먼저/다음은/마지막으로)가 순서로 자동 판정. 1개만 넣으면 단독. 묶음은 한 번에 다 넣을 것(도중 추가/삭제 시 순서 바뀜)
  • 번인 미체크 시 ✋ 검수대기에서 멈춤 → 항목 클릭해 확인 후 이어서
  • 서버 재시작해도 완료된 단계는 파일 기준으로 건너뛰고 이어서 진행

6. 결과가 마음에 안 들 때

상황버튼/방법효과
내레이션 톤·내용이 별로③ 행의 🔁 내레이션 재생성 컷·대사는 그대로, 내레이션만 6슬롯 규칙(소개→장면묘사→평가→질문)으로 재작성
고른 구간 자체가 별로③ 행의 🔁 구간 재선정 LLM이 keep을 다시 골라 final.mp4 재컷 + 자막까지 자동 재생성 (기존 덮어씀)
문구 몇 개만 고치고 싶음✎ 자막 편집 섹션 내레이션·대사를 직접 수정 → 저장 → 다시 굽기
재생성 후TTS와 번인은 다시 실행해야 새 내레이션이 반영됩니다

8. tools/ — 단독 실행 CLI

GUI 없이 출력 폴더를 직접 손볼 때. 설정은 studio_config.json 공유.

python tools/run_single.py MIDA-999        # trim.mp4 폴더 전체 파이프라인(전사→메타→LLM→SRT)
python tools/replan.py <폴더>              # keep 재선정 + final 재컷 (GUI 버튼과 동일 로직)
python tools/regen_narration.py <폴더>     # 내레이션만 재생성 (GUI 버튼과 동일 로직)
python tools/transcribe_hq.py --video X.mp4  # 고품질 전사 + Claude 검증 리포트(품질 판단용)

9. 문제 해결

증상원인 / 해결
cublas64_12.dll not found venv가 아닌 시스템 파이썬으로 뜬 것. run.bat으로 기동. 첫 설치면 setup_gpu.bat
② AI가 "자막을 보내달라"며 거부 콘텐츠 거부가 아니라 프롬프트 전달 문제였던 케이스 — 현재는 stdin 전달로 해결됨. 재발 시 수동 모드 사용
TTS가 몇 분씩 멈춘 듯 정상 — GPU 느릴 때 문장당 수 분. 600초까지 기다림. 도중 강제종료하면 voicebox 큐에 좀비 잡이 쌓여 더 밀림
배너가 신작 품번을 못 찾음 로컬 jav_scrap\jav_2026.db가 구버전 — 우분투에서 scp로 동기화(+images_actress/)
voicebox 기동 실패 (포트 17493) iphlpsvc 서비스가 포트 선점 — 서비스 중지 → Voicebox 실행 → 서비스 재시작
풀오토 아이템이 ⏳ 대기만 반복 voicebox 또는 meta_api가 죽어 있음. 켜면 60초 안에 자동 진행
완성본에 총평·별점이 없음 내레이션이 keep 밖으로 나간 케이스 — 자동으로 끝에서부터 재배치됨. 로그의 재배치 경고 확인
mkv가 미리보기에 안 나옴 브라우저 제약 — 처리 자체는 되므로 그대로 진행하거나 mp4 권장
요약 — 평소엔 풀오토(감시 폴더)에 던지고, 특별히 신경 쓸 영상만 ① 잘라내기로 정사장면 직접 빼고 큐에 넣는다. 완성본은 _완성\에서 수거, 업로드 전 눈으로 한 번 검수.
