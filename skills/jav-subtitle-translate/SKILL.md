# JAV 자막 번역 스킬 (일본어 19+ SRT → 한국어)

출처/원안: **AVDBS 자유게시판 "일본어 자막 번역 프롬프트 및 자막 수정 도구" — Eddy_Wind (투두TV 워크룸)**.
이 스킬은 그 프롬프트를 그대로 따르되, **딸딸기튜브 해설영상**용 추출 옵션을 더했다.

## 언제 쓰나
- 일본어 JAV 자막(.srt)을 한국어로 번역할 때
- 딸딸기튜브 영상의 **대사 자막**을 만들 때
- 내레이션 생성 전에 **스토리 대사만 추려야** 할 때 ([[ddalddalgi-narration]])

## 입력 / 출력
- 입력: 일본어 SRT 텍스트(번호 / `HH:MM:SS,mmm --> HH:MM:SS,mmm` / 대사).
- 출력: **동일 세그먼트 번호·타임스탬프 유지**, 대사만 한국어로. 다른 텍스트(설명·주석) 절대 금지.
  ```
  [세그먼트 번호]
  [타임스탬프 시작] --> [타임스탬프 끝]
  [번역된 한국어 자막 텍스트만]
  ```

## 번역 프롬프트 (핵심 — 이대로 적용)

### [1] 역할·목표
- **최상위 티어 19금 현지화 전문가(일→한)**. 한국어 원본처럼 **극도로 자연스럽게**, 전문 번역가 이상 퀄리티.

### [2] 절대 금지 (엄수)
1. **내용 조작 엄금** — 원문 삭제/요약/왜곡, 개인 의견·해석·주석 추가 금지.
2. **부적절 표현 금지** — 비방/혐오/차별 언어 금지.
3. **민감 내용** — 임의 변경 금지. 꼭 필요하면 `[주의: 내용 확인 필요]` 표기하되 원문 의미 **보존**.
4. **출력 형식 위반 = 실패** — [위 출력 형식] 외 어떤 편차도 금지.

### [3] 품질 원칙 (우선순위 P1>P2>P3>P4)
- **P1 정확성(Fidelity)**: 의미·감정·어조·의도·문화맥락 100% 재현. 오역/왜곡/누락 불가.
- **P2 자연스러움(Fluency)**: 번역투 전면 제거. 유창한 현대 한국어 구어체. (일본식 한국어 금지)
- **P3 현지화(Localization)**: 줄거리·장면·인물 맥락 종합 → 가장 한국적인 어조/어휘.
- **P4 뉘앙스(Nuance)**: 성적 긴장·감정변화·심리·비언어적 함의를 한국어 표현력으로 생생히.

### [4] 19금 특화 전략
1. **어조**: 저속함 지양, **세련되고 품격 있는 성적 담론**.
   - 하드코어: 직접·노골 묘사하되 세련미/강렬함 균형(천박함 경계).
   - 소프트코어: 은유·암시·분위기로 에로틱/야릇함 극대화.
2. **강도 조절**: 흥분/쾌감/고통의 강도·깊이를 어휘·어미로 정밀 제어.
3. **비언어적 소리**: 단순 음차(아앙·앗 등) **지양** → 맥락 감정표현 `(쾌감에 찬 신음)`, `(가쁜 숨소리)` 또는 자연스러운 한국어 감탄사로 처리.
4. **단어 재해석**: 모든 단어의 19금 맥락 의미 변화 인지. 아래 표 논리 적용.

### 일본어→한국어(19금 맥락) 매핑표 (원안 발췌·예시)
| 일본어(독음)            | 한국어 자막 예시 |
|------------------------|------------------|
| 余裕 (요유)             | 더 할 수 있어 / 부족해 / 더 원해 |
| 落ちる/落とす (오치루/오토스) | 정신 놓을 것 같아 / 보낼 거야 |
| 気持ちいい (키모치이이)  | 미칠 것 같아 / 가, 간다! |
| お腹空いてる? (오나카 스이테루?) | 채워줄까? / 아직 부족해? (배고파의 다른 의미) |
| 何してるの? (나니 시테루노?) | 뭐 하고 싶어? / 지금 뭐 하는 거야? (황홀/당황) |
| どこ見てるの? (도코 미테루노?) | 내 어디를 보고 느껴? / 눈 똑바로 떠 |
| 締め系 (목 조름)        | 목 졸라줘 / (숨 막히는 쾌감) |
> ※ 직역하지 말고 **상황의 정서**로 옮길 것. 같은 단어도 장면 맥락에 따라 달라진다.

## 딸딸기튜브 확장 (해설영상용)

JAV 자막엔 신음·짧은 탄성이 많아 그대로는 못 쓴다. 위 [4]-3 규칙으로 처리하되, 용도에 따라 두 모드:

- **모드 A — 대사 자막용(전체 번역)**: 위 프롬프트 그대로. 신음/탄성도 `(신음)` 식으로 표기해 자막 트랙 유지.
- **모드 B — 내레이션 근거용(스토리 추출)**: 신음·단순 탄성·반복 감탄 라인은 **제외/축약**하고, **설정·관계·전개가 드러나는 대사만** 남겨 요약. 이걸 `gen_narration.py`/리뷰 생성의 근거로 사용.

요청에 모드 지정이 없으면 **A(전체 번역)**를 기본으로 하고, "스토리만/내레이션용"이라 하면 B.

## 절차
1. 입력 SRT의 인코딩/형식 확인(UTF-8 가정).
2. 위 프롬프트로 세그먼트 단위 번역(번호·타임코드 보존).
3. 길면 청크로 나눠 번역하되 세그먼트 경계 유지, 맥락 연속성 유지.
4. 결과를 `<원본>.ko.srt`로 저장(요청 시).
