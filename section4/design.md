# 섹션4 인트로 — 비주얼 방향

> 2026-09-08. 초안 1~3이 "어두운 배경에 텍스트 얹기"로 밋밋했던 원인은 방향을 안 정하고
> 프레임마다 땜질했기 때문. 여기서 정한 것만 쓴다.

## 콘셉트 — 심야 랭킹 방송

케이블 심야 순위 프로그램의 화면. 화면 어딘가에 **항상 방송 프레임이 있고**,
숫자는 그래픽이 아니라 **세트의 일부**처럼 크게 박힌다. 슬라이드가 아니라 방송이다.

세 가지가 이걸 만든다:

1. **지속 프레임** — 상단 러닝헤드(`9월 첫 주 · JAV 신작 랭킹`)와 하단 **순위 티커**(12→1 점열)가
   전 구간 유지된다. 시청자가 "지금 어디쯤"인지 항상 안다. 씬이 바뀌어도 화면이 리셋되지 않는다.
2. **좌측 정렬 편집 레이아웃** — 가운데 정렬 금지. 텍스트 블록은 왼쪽 세로 핑크 룰에 붙는다.
   큰 숫자만 오른쪽에서 **화면 밖으로 잘려 나간다**(bleed).
3. **질감** — 그레인 + 비네트 + 미세 스캔라인. 평평한 검정이 "빈 슬라이드"로 보이는 걸 막는다.

## 색

| 역할 | 값 | 쓰는 곳 |
|---|---|---|
| 배경 | `#0d0a0c` → `#1c1116` 라디얼 | 전체 |
| 핑크(솔리드 위) | `#ff2d55` | 룰·티커 활성·숫자 강조 |
| 핑크(영상 위) | `#ff5c7d` | 자막 숫자·로고 (WCAG 3:1) |
| 흰색 | `#ffffff` | 주 텍스트·숫자 |
| 회색 | `#9b929a` | 라벨·비활성 티커 |

**노랑은 뺐다.** 색이 셋이면 어느 것도 강조가 아니다. 핑크 하나만 강조로 쓴다.

## 타이포

| 용도 | 폰트 | 크기·굵기 |
|---|---|---|
| 숫자·순위 | **Paperlogy ExtraBold** | 260~420px, `letter-spacing:-.05em` |
| 헤드라인 | Paperlogy Bold | 90~140px |
| 본문·자막 | **Pretendard Variable** | 자막 56px / 라벨 30~44px |
| 러닝헤드·티커 | Pretendard | 28~32px, `letter-spacing:.14em`, 대문자 느낌 |

숫자는 **항상 Paperlogy**. 본문과 같은 폰트를 쓰면 숫자가 정보가 아니라 문장이 된다.

## 영상 소재 처리

납품본에는 **인포카드 배너가 이미 구워져 있다**(우상단). 그대로 쓰면 인트로에 남의 배너가 뜬다.
→ 몽타주는 `clip-path: inset(26% 0 22% 0)` 로 **가운데 띠만 잘라 쓴다**. 배너도 자막도 잘려 나가고
필름 스트립처럼 보인다.

## 모션

- **하드컷 우선.** 크로스페이드는 씬 전환에서만, 그것도 0.25초 이내.
- 숫자는 `back.out(2.4)`로 **오버슛하며 꽂힌다**. 페이드인 금지.
- 티커는 순위가 넘어갈 때 **한 칸씩 딱딱 이동**(스텝 모션, 이징 없음).
- 카운트다운은 한 장씩 교체. 나열 금지(초안1 실패).

## 하지 말 것

- 가운데 정렬 텍스트 블록 (숫자 단독 제외)
- 회색 반투명 자막 박스 → 좌측 정렬 + 핑크 세로 룰
- 색 3개 이상
- 부드러운 페이드로만 이어지는 전환
- 평평한 단색 배경(그레인·비네트 없이)
