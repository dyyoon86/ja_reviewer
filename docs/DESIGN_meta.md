# DESIGN — Meta 스타일 (ja_reviewer 내부 도구용)

`tools/review_sheet.py`(`_검토.html`) 같은 내부 검토 화면에 쓰는 디자인 규칙.
Meta(meta.com) 디자인 언어를 따르되, 한글 가독성을 위해 폰트만 Pretendard로 바꾼다.

## 1. 원칙
- **밝고 넓게** — 흰 카드 + 아주 옅은 회청색 바탕. 장식 없이 여백으로 구분한다.
- **파랑은 한 가지 뜻** — Meta Blue는 "선택됨 / 지금 재생 중 / 누를 수 있음"에만 쓴다.
- **둥글게** — 버튼·칩은 완전한 알약(pill), 카드는 큰 라운드.
- **그림자는 거의 없게** — 카드만 아주 옅은 그림자, 나머지는 1px 선.

## 2. 색 토큰
| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--bg` | `#F1F4F7` | `#0B1014` | 페이지 바탕 |
| `--surface` | `#FFFFFF` | `#1C2B33` | 카드 |
| `--surface-2` | `#F1F4F7` | `#25353E` | 카드 안 보조면, 비선택 칩 |
| `--line` | `#DEE3E9` | `#34474F` | 1px 구분선 |
| `--text` | `#1C2B33` | `#F1F4F7` | 본문 |
| `--text-2` | `#465A69` | `#B4C0C8` | 보조 글자 |
| `--text-3` | `#67788A` | `#8595A0` | 시간·메타 |
| `--blue` | `#0064E0` | `#4A9BFF` | 선택·재생 중·링크 |
| `--blue-soft` | `#E8F1FD` | `#14304F` | 내레이션 줄 바탕 |
| `--warn` | `#F7B928` | `#F7B928` | 주의(읽기 속도 초과) |
| `--danger` | `#E41E3F` | `#FF5C75` | 오류 |

내레이션 = 파랑 계열(우리가 쓴 글), 대사 = 무채색(원본에서 온 글)으로 구분한다.

## 3. 타이포
- 패밀리: `Pretendard Variable` → `Pretendard` → `system-ui` (Meta의 Optimistic 대체)
- 크기: 제목 22/700 · 섹션 16/700 · 본문 15/400 · 보조 13/500 · 시간 13 tabular-nums
- 줄간격 1.5, 자간 -0.01em(제목만 -0.02em)

## 4. 모양
- 라운드: 칩·버튼 `999px` · 카드 `20px` · 줄(row) `12px` · 영상 `16px`
- 그림자: 카드만 `0 1px 2px rgba(28,43,51,.06), 0 4px 16px rgba(28,43,51,.06)`
- 간격 단위 4px — 8 / 12 / 16 / 24 / 32

## 5. 컴포넌트
- **헤더**: 흰 바, 왼쪽 제목(배치명) + 편 수, 아래 줄에 편 칩 가로 스크롤.
- **칩(편 선택)**: 알약, 비선택 `--surface-2`, 선택 `--blue` 바탕 흰 글자. 순위는 굵게.
- **세그먼트 탭(타임라인/줄거리)**: 회색 알약 트랙 안에 흰 알약이 선택 표시.
- **타임라인 줄**: 라운드 12, 내레이션은 `--blue-soft` 바탕 + 왼쪽 3px 파란 막대, 대사는 바탕 없음.
  지금 재생 중인 줄은 `--blue` 1.5px 테두리.
- **태그**: 작은 알약 12px, `--surface-2` 바탕. 주의 태그는 `--warn` 바탕.
- **자막 미리보기(영상 아래)**: 검은 판 위 흰 글자(실제 자막처럼), 내레이션 줄은 파란 라벨.

## 6. 하지 말 것
- 파랑 외 강조색 추가, 그라데이션, 굵은 그림자, 이모지·유니코드 기호를 아이콘 대신 쓰기.
