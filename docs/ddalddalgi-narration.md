# 딸딸기튜브 — 신작 해설 내레이션 프로젝트 (진행중)

> jarank(jav_2026.db) 작품을 영상으로 만드는 작업. jav_scrap의 데이터/도구를 재사용하지만
> 산출물은 **유튜브 @ddalddalgi_tube** 용 영상 대본.

## 최종 목표 (포맷)

3분휴지처럼 **처음부터 끝까지 내레이션**이 아니라:

- **실제 작품 대사가 흐르고**(한국어 자막으로 표시) — 필요하면 원음은 **무음 처리**하고 그 위에 내레이션
- **중간중간 내레이터가 끼어들어/오버레이**로 설명·코멘트 (해설형 믹스)
- 자막 트랙 2개 가능: **① 실제 대사 자막 ② 내레이션 자막** (둘 다 보여줄 수 있음)

즉 "대사 + 해설 내레이션 interleave" 영상. (3분휴지 = 연속 내레이션, 우리 = 해설 끼임형)

## 스타일 레퍼런스 (3분휴지 / 3M TISSUE 분석 완료)

- **작품당 4단**: 전환("다음은 ○○○의 신작입니다") → 시놉시스 → 솔직 평가 → 총평
- **톤**: 정중체(~습니다) + 솔직 호불호 + 가벼운 촌평 유머
- **마니아 은어**: 미드(가슴)·포텐·폼·피지컬·육덕·고인물·하메리(POV데이트)·1인칭(POV)·해금작·평타·NTR·진삼국무쌍(다대일) + 레이블(마돈나·S1·무디즈·SOD)
- 아웃트로: 채널 안내 + "지금까지 ○○○였습니다"

## 데이터 소스 (품번 → 전부 조회)

`jav_2026.db` 에서 품번으로: 배우(한/일)·생일·혈액형·**스리사이즈 실수치**·레이블·메이커·감독·시리즈·장르·태그·일본원제·**한국어 시놉시스(description)**·인기(조회/좋아요/싫어요).
→ `gen_narration.py` 의 `fetch_meta()` 가 담당.

## SRT (필수, interleave형에선)

- 입력: 일본어 SRT(타임코드 포함). 내레이션을 **타임라인 특정 지점**에 꽂아야 하므로 필요.
- ⚠️ **선정적 대사 필터링 필수** — JAV SRT엔 신음·짧은 탄성 등 못 쓰는 대사 多.
  스토리/설정 대사만 추려서 내레이션 근거로 사용. (구현 예정)

## 만든 것 / 상태

- `gen_narration.py` — 품번(+SRT) → DB 전체조회 → 3분휴지 스타일 **연속 내레이션** 리뷰 생성(codex).
  - 현재는 "연속 내레이션형". **interleave(해설끼임)형은 다음 단계.**
- 평가 방식: 영상을 못 보므로 **평가/비교는 창작(옵션2 선택)**. 시놉시스·메타·인기는 사실 근거.

## 블로커

- **codex 토큰 revoke** (refresh_token_invalidated) → gen_narration·gen_hooks 자동실행 불가.
  - 해결: 미니PC `codex login`(헤드리스 OAuth 콜백이라 까다로움) 또는 **OpenAI API 키**(권장, 접속 불필요).
  - 당장은 **Claude(대화)로 직접 생성** 중.

## 다음 단계 (체크하며 개선)

1. SRT **interleave 대본 생성기** — [타임코드] 대사 / [타임코드] 🎙내레이션 형식 출력
2. SRT **선정적 대사 필터** (스토리 대사만 추출)
3. 일→한 대사 번역(자막용)
4. 시그니처 확정 — 별점 기준 / 캐치프레이즈(인트로·아웃트로)
5. 자동화: OpenAI API 키 붙이면 무인 배치 가능
